# Issues identified in the starter code

HTML issues
1. No navigation on any page.
2. Non-semantic structure — every section was a generic <div> instead of
   header, nav, main, section, article, footer.
3. Missing lang attribute on <html>, and no meta charset or viewport tag
   on any page — a validation, responsiveness and accessibility failure.
4. All images missing alt text.
5. About page: skills table completely missing, left as a comment only.
6. Projects page: third project missing, and only 2 images site-wide
   (below the required 5+).
7. Contact form had no <label> elements, no id/name attributes, and only
   two input types (both text, one should have been email).
8. No validation attributes on the form (required, pattern, minlength).
9. Stylesheet linked as css/styles.css but supplied flat as styles.css,
   so it never loaded.
10. Duplicated, meaningless <div class="footer"> blocks with no working
    mail link markup.

CSS issues
11. Only 2–3 selector types used — no ID, descendant or pseudo-class
    selectors, and no combinators.
12. No :hover/:focus states — no feedback for mouse or keyboard users.
13. Poor colour contrast — light-blue hero background with default text
    colour fell below the 4.5:1 WCAG AA ratio.
14. Footer was text-align: left despite a comment saying it should be
    centred.
15. No navigation styling at all, despite a comment flagging it missing.
16. No table or form styling — no borders, spacing, alternating rows or
    visual hierarchy.
17. Minimal box-model usage — almost no margin/padding/border variety.
18. No responsive behaviour — a single fixed layout broke on narrow
    screens.

How I fixed them
I rebuilt each page with semantic elements (header, nav, main, section,
article, footer), added a shared nav menu with aria-current, and wrote
alt text for every image. I built the skills table, completed the third
project card, and rebuilt the contact form with seven input types,
labels on every field, and required/minlength/pattern validation. On
the CSS side I fixed the stylesheet path, expanded selector variety
(element, class, ID, descendant, attribute, pseudo-class), fixed
contrast, centred the footer, added hover/focus states, styled the
table and form, demonstrated the box model, and added a mobile
breakpoint. I later replaced leftover footer <div> wrappers with
<section> and <hr> to stay within the 3-div limit, and added the
missing lang="en" on about.html.
